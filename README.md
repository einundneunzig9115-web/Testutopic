# Test Utòpic de Poti · v0.11

## Què canvia
- Es conserven les 33 preguntes i les tres dimensions originals.
- Les preguntes sobre realitat i coneixement utilitzen llenguatge intuïtiu, sense exigir coneixement de termes com Nous, gnosi o hermetisme.
- S’han enriquit perfils individuals perquè es distingeixin millor: Plató, Spinoza, Leibniz, Hegel, William James, Schopenhauer, Agustí d’Hipona, Ramana Maharshi, Vasubandhu, Śāntideva i Buda.
- S’hi incorpora Maimònides i s’enforteixen els matisos de les tradicions neoplatònica, hermètica, gnòstica, sufí, vedàntica i budista.
- Cada fitxa individual inclou una explicació de l’afinitat, una cautela contra equivalències massa fàcils i una obra d’entrada. Les fonts dels autors gnòstics antics es marquen com a fragmentàries o indirectes.
- Les etiquetes específiques són senyals interns del model; no s’exposen com a vocabulari obligatori a qui respon.
- Les afinitats ponderen menys els conceptes massa comuns i rebaixen les fitxes exploratòries, per reduir puntuacions inflades basades en coincidències genèriques.
- La biblioteca incorpora filtres combinables per àmbit, tema, tradició i profunditat, amb cerca per nom com a opció secundària i càrrega progressiva de resultats.

## Publicació a GitHub Pages
1. Descarrega el ZIP i descomprimeix-lo.
2. Al directori arrel del repositori, substitueix `index.html` i `pensadores_catalogo.json` si el repositori fa servir aquest nom; en aquesta versió el fitxer de catàleg es diu `pensadores_catalogo.json`.
3. Mantén també `manifest.webmanifest`, `icon-192.png` i `icon-512.png`.
4. No eliminis el repositori ni canviïs la configuració de Pages per publicar aquests fitxers.

## Límits
És un test filosòfic exploratori, no una prova psicomètrica validada. Les puntuacions expressen similitud temàtica interna, no probabilitats ni diagnòstics. Una fitxa individual és una aproximació interpretativa documentada, no una auditoria exhaustiva de tota l’obra de l’autor.
